# Security

## Reporting a vulnerability

Email support@zevari.ai with "Security" in the subject. Include what you found, how to reproduce it and what it affects. Please don't open a public issue for a vulnerability.

We will confirm we got it and keep you updated until it's fixed.

## Scope

This repo holds instructions (two skills) and an MCP config. It runs no code of its own. It connects your agent to the Zevari MCP server at `https://mcp.zevari.ai/mcp`, which uses OAuth or a Zevari access token. Nothing sends to LinkedIn or email until you approve it.

Report issues in the Zevari service itself to the same address.
